# HL7 Europe Base and Core FHIR IG R4

This repository contains the FHIR 4.0.1 version of the HL7 Europe Base and Core FHIR IG.

* Current build: https://build.fhir.org/ig/hl7-eu/base/
* Feedback on the specification is tracked using [HL7 Jira](https://jira.hl7.org/secure/Dashboard.jspa?selectPageId=17801).
* More information on the IG, meeting minutes and telco details can be found on [HL7 confluence](https://confluence.hl7.org/spaces/HEU/pages/265491037/Base+Profiles).

This repository is not edited manually. Its content is generated from the sources in
https://github.com/hl7-eu/base-multi-versions, which holds the R4 and R5 versions of this
guide in a single codebase. Changes have to be made there — anything committed here directly
is overwritten by the next deployment.
